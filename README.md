## 简介

本项目是一套基于 Varlet UI 深度封装的企业级自研手机端 Web 组件库，面向中后台数字化业务场景设计，借鉴 SAP 等主流 ERP 软件成熟设计理念与交互规范，高度贴合企业管理系统、业务流程类应用开发需求。
组件库配套标准化业务开发模板，依托前端微应用乾坤框架实现多业务微应用统一集成，内置 AI 协同开发辅助能力，剥离底层通用交互、页面搭建冗余工作，让研发人员聚焦核心业务逻辑开发，大幅缩短业务页面交付周期。

> 业务应用基于 Spring Boot + Spring Cloud + Nacos + Redis + RocketMQ 等微服务架构开发，前端基于 Vue + Element-Plus UI
> 等实现，支持多种数据库Mysql、Oracle、达梦等，也可自选前后端技术框架，数字化平台提供的组件库与业务应用可快速无缝融合，业务应用开发完全基于原生，利于员工成长，企业自主可控。
